# آرایه مدرن — Araye Modern

وب‌سایت رسمی شرکت **آرایه مدرن (Araye Modern)** — مهندسی صنعتی، ساخت دقیق قطعات، تجهیزات دریایی و اتوماسیون.

## بخش‌های وب‌سایت
- **صفحه اصلی فارسی:** هیرو، معرفی خدمات، ماشین‌آلات، کنترل کیفیت، و اطلاعات تماس (بوشهر، ایران)
- **صفحات داخلی:** درباره ما، خدمات، صنایع، پروژه‌ها، ماشین‌آلات، کنترل کیفیت، تماس با ما، استعلام قیمت
- **نسخه‌های بین‌المللی:** انگلیسی (`/en`) و عربی (`/ar`)

## ساختار آدرس‌ها
سایت با آدرس‌های **بدون پسوند** کار می‌کند. دامنهٔ اصلی `arayemodern.ir` است و دامنهٔ `arayemodern.com` به آن ریدایرکت می‌شود.

| آدرس عمومی | فایل روی سرور |
|---|---|
| `/fa` | `fa.html` |
| `/fa/services` | `fa/services.html` |
| `/en/quote` | `en/quote.html` |

ریدایرکت از شکل قدیمی (`.html`) به شکل جدید با کد ۳۰۱ انجام می‌شود، بنابراین لینک‌های قدیمی و آدرس‌های ذخیره‌شده در گوگل از کار نمی‌افتند.

## نحوه اجرا (بدون نیاز به پکیج خارجی)
این پروژه نیازی به `npm install` ندارد و مستقیماً با Node.js اجرا می‌شود:

```bash
npm start
```

سپس در مرورگر باز کنید: `http://localhost:3000/fa`

سرور محلی همان قواعد `.htaccess` را شبیه‌سازی می‌کند (آدرس بدون پسوند، ریدایرکت ۳۰۱، خطای ۴۰۴ واقعی).

## استقرار

### هاست اشتراکی (Apache / LiteSpeed / cPanel)
فایل `.htaccess` در ریشهٔ سایت قرار دارد و به‌صورت خودکار این موارد را انجام می‌دهد:
- اجبار HTTPS
- یکسان‌سازی دامنه (بدون `www`، و `.com` → `.ir`)
- تبدیل آدرس‌های بدون پسوند به فایل‌های `.html`
- ریدایرکت ۳۰۱ از آدرس‌های قدیمی `.html`
- کش فایل‌های ایستا، فشرده‌سازی، و هدرهای امنیتی

### Vercel
فایل `vercel.json` تنظیمات `cleanUrls` و ریدایرکت را در اختیار Vercel می‌گذارد.

### نکتهٔ دامنهٔ `.ir`
دامنه‌های `.ir` فقط به IP و هاست داخل ایران وصل می‌شوند. بنابراین استقرار باید روی هاست ایرانی انجام شود.
